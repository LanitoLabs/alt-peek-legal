# Alt Peek Privacy Policy

Last updated: July 22, 2026

Alt Peek is a browser extension that opens user-requested links in an overlay and provides related features such as copying links and searching selected text. This policy explains what information the extension handles and how it is used.

## Information Alt Peek Handles

Alt Peek processes the minimum information required to provide its user-facing features:

- **Web browsing activity:** hostnames of open tabs used to display the correct extension-icon state, links the user chooses to preview or open, and the destination URL currently displayed in a preview.
- **Website content:** links under the pointer, text the user explicitly selects when the selected-text search feature is enabled, and terms the user types into the in-preview find bar.
- **Extension settings:** theme, feature toggles, disabled hostnames, visual preferences, and other configuration choices.
- **Local interface state:** non-identifying state used for optional support-page visual details, such as the date on which a support button was clicked.

Alt Peek does not intentionally collect form entries, passwords, authentication information, payment information, personal communications, or complete browsing history.

## How Information Is Used

The information above is used only to provide features requested by the user, including:

- displaying a selected link inside the Alt Peek overlay;
- opening or copying a selected link;
- enabling or disabling Alt Peek for a hostname;
- searching text after the user selects it and activates the search button;
- finding text locally inside the currently open preview after the user presses Ctrl+F; and
- applying and synchronizing the user's extension preferences.

URLs and selected text are processed locally by the extension and are not sent to servers controlled by Alt Peek or Lanito Labs.

Terms entered into the in-preview find bar are used only to locate matching text in the currently open preview. They are not stored, transmitted over the network, or sent to servers controlled by Alt Peek or Lanito Labs.

When the user opens a preview, the browser connects directly to the destination website. That website may receive information normally included in a web request, such as the requested URL, IP address, cookies, or other browser-provided information, according to that website's own privacy policy.

When the user activates selected-text search, the selected text is submitted to Google as a search query over HTTPS. This happens only after an explicit user action and is subject to Google's privacy policy.

## Storage and Retention

Extension preferences and disabled hostnames are stored using Chrome's synchronized extension storage. Chrome may synchronize those preferences between browser profiles connected to the same Google account according to Chrome's own synchronization and privacy settings. Non-identifying support-page interface state is stored using Chrome's local extension storage.

Alt Peek does not maintain a developer-controlled database. Preview URLs and selected text are not retained by Alt Peek after the requested action. Stored settings remain until the user changes them, clears extension data, or uninstalls the extension, subject to Chrome's synchronization behavior.

## Sharing, Sale, Analytics, and Advertising

Alt Peek does not sell user data. It does not include analytics, telemetry, advertising trackers, or behavioral profiling. Alt Peek does not share browsing data with Alt Peek or Lanito Labs servers because no such data-collection server is used.

The optional donation page opens Stripe in a separate browser page. Payment information is handled directly by Stripe and is not received or stored by the extension. The optional cryptocurrency address is public and copying it does not transmit information to Alt Peek.

## Security and Permissions

Alt Peek requests access to HTTP and HTTPS pages so its visible preview, link-copy, selected-text search, and per-site controls can work on supported websites. It uses a temporary, tab-scoped browser rule while a preview is active to permit compatible websites to appear inside the user-requested preview. The rule is removed when the preview closes or its source tab navigates.

Alt Peek does not execute remotely hosted code.

## User Control and Deletion

Users can disable individual features, disable Alt Peek on specific hostnames, clear the disabled-host list, clear extension data through Chrome, or uninstall the extension at any time.

## Limited Use

Alt Peek's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only to provide or improve the extension's disclosed, user-facing features.

## Changes to This Policy

This policy may be updated when Alt Peek's features or data practices change. The date at the top of this document identifies the latest revision. Material changes will be disclosed through the extension or its Chrome Web Store listing as required.
